联保智调 - Windows 离线演示包

1. 适用系统：Windows 10/11 64 位。
2. 使用方式：解压 ZIP 后，双击“启动联保智调离线版.cmd”。浏览器会自动打开本机页面。
3. 停止方式：双击“停止联保智调离线版.cmd”。
4. 本包不需要安装 Python、Node.js 或 Docker，也不访问公网服务器。
5. AI 功能默认使用基于当前权威仿真事实的确定性解释；本包不包含、读取或要求任何 API 密钥。
6. 数据仅为匿名合成教学场景。仅供教学仿真与辅助决策使用，不构成真实机场运行、放行、登机、改签或车辆控制指令。
7. 本包为比赛演示用开源构建，当前未购买 Windows 代码签名证书；若 SmartScreen 首次提示“无法识别的应用”，请先核对 Release 附带的 SHA256SUMS.txt，再选择“更多信息 -> 仍要运行”。
