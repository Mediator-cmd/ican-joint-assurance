## 视频验收脚本

1. 首屏显示匿名合成场景和安全声明。
2. 启动仿真时钟，展示任务、资源、事件和方案随权威快照变化。
3. 等待或注入一个已验证教学扰动，展示事件定位和候选重规划。
4. 人工确认候选，展示当前方案实线、候选虚线和任务变化。
5. 用一个与任务或资源相关的问题触发空间 AI 只读回答，显示 `SPATIAL-FACT-*` 证据和当前 revision。
6. 说明无模型时确定性回退仍可完成闭环；全程不出现真实机场、旅客个人信息或生产控制指令。

## 一致性检查

- 项目名称统一为“联保智调”。
- 所有截图、视频和 PDF 使用同一匿名场景版本与同一安全声明。
- 性能数字只引用 `docs/m6-benchmark-report.json` 和 M6-6 审查，不把临时样本写成生产承诺。
- 公网地址只有在平台健康检查和连续三次演示通过后才可写入材料。
