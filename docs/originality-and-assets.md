# 原创与资产说明

## 代码与数据

- 联保智调业务代码、界面交互、调度模型封装、测试和文档由本项目开发过程产生。
- `data/` 中的场景是匿名合成教学数据，不来自真实机场生产系统，不包含姓名、证件号、联系方式或真实航班运行记录。
- M6 规模场景由确定性工厂生成，用于可复现压力验证，不代表真实机场容量或服务承诺。

## 空间资产

- 首次发布使用仓库内原创、匿名 2D SVG 航站楼示意图和程序化路径标记。
- 不使用北京大兴机场平面图、商业地图截图、内部运行图、真实坐标或限制区细节。
- 空间图中的区域、坐标、资源位置和路径均为教学仿真表达，不能反推任何真实机场布局。

## 第三方依赖

React、TypeScript、Vite、FastAPI、Pydantic、OR-Tools、Uvicorn、Vitest、Lucide 等依赖保留各自上游许可证；发布前应从锁文件和依赖元数据生成最终依赖清单，并在仓库根目录明确选定项目许可证。

## AI 辅助标注

DeepSeek 仅可作为事件理解和权威事实表达的辅助模型。模型输出经过结构校验、事实白名单和 revision 绑定；核心调度与硬约束复核由项目确定性代码完成。比赛材料应按主办方要求标注 AI 辅助制作，不把模型输出冒充为人工原创事实或真实运行指令。
