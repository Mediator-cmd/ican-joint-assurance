# M7 发布准备与公网地址规划

## 1. 目的与边界

M7 负责把已完成的 M6 仿真版本整理为可公开审阅、可复现构建、可按说明部署的比赛交付物。项目已经取得公开 GitHub 仓库、阿里云 ACR 镜像和可访问的阿里云轻量服务器地址；本文件同时记录当前部署事实和仍未完成的 HTTPS、材料与连续演示门槛。

本阶段仍保持以下边界：

- 只使用匿名合成教学数据和项目原创 2D 空间示意图，不接真实机场生产系统、真实坐标、内部运行图或旅客个人信息。
- AI 只读解释和事件理解；不应用事件、推进仿真时钟、采用候选方案或控制资源。
- 单 origin、单实例、一个 Uvicorn worker、SQLite 持久化卷是首次公开版本的明确限制。
- DeepSeek 密钥只由后端运行环境注入。当前轻量服务器使用 `600 root:root` 的服务器端环境文件；密钥不进入 Git、Dockerfile、镜像层、前端构建产物、响应或日志。

## 3. 发布架构契约

### 3.1 首次公开版本

```text
公网 HTTP（当前固定 IPv4；HTTPS 待域名与备案）
  -> 阿里云轻量应用服务器
  -> 一个 Docker 容器
  -> 一个 Uvicorn worker
  -> FastAPI + Vite 同源服务
  -> 持久化卷 /data/runtime-sessions.sqlite3
```

- GitHub Actions 构建 Dockerfile 并推送 ACR；服务器从 ACR 拉取同一不可变内容的 `latest` 镜像。
- 健康检查固定为 `GET /api/v1/health`，必须返回 HTTP 200 和 `status: ok`。
- 只配置一个副本。SQLite、内存 SSE 缓冲和运行会话恢复均不支持横向扩容。
- 容器使用 `--restart unless-stopped`。服务器每 5 分钟比较 ACR 镜像 ID；新镜像健康检查失败时恢复上一容器，不删除 SQLite 命名卷。
- 发布前后的 smoke 必须验证：首页 200、健康检查 200、创建/恢复匿名仿真会话、SSE、事件与候选、真实模型只读路径和确定性回退。

### 3.2 服务器端秘密配置

只允许配置以下后端变量：

| 变量 | 是否必需 | 说明 |
| --- | --- | --- |
| `AI_API_KEY` | 可选 | DeepSeek API 密钥；仅存在服务器端 root 可读环境文件并注入后端容器 |
| `AI_BASE_URL` | 配置 AI 时必需 | OpenAI-compatible 根地址，例如 `https://api.deepseek.com` |
| `AI_MODEL` | 配置 AI 时必需 | 已验证模型名由部署前 smoke 确认 |
| `AI_TIMEOUT_SECONDS` | 可选 | 模型请求超时；保持有限值 |

未配置 AI 时，事件规则解析、CP-SAT 调度、方案解释和空间问答的确定性路径仍必须可用。模型调用只增强表达，不能成为核心闭环的启动前置条件。

### 3.3 回滚

1. 保留上一份已验收镜像和上一份 Git commit 的可构建来源。
2. 新版本先通过健康检查和匿名闭环 smoke，再切换公网流量。
3. 若健康检查、SQLite 恢复、模型只读边界或演示流程失败，立即切回上一镜像；不要在故障期间修改生产 SQLite 文件结构。
4. 回滚后保留部署日志中的版本标识、失败检查项和时间，不记录密钥、用户原文或旅客信息。

## 6. 禁止事项

- 不把 DeepSeek key、任何 `.runtime` 文件、SQLite 会话、服务日志或截图缓存加入 Git。
- 不把“本地地址”“平台预览地址”写成稳定公网地址。
- 不把匿名机场示意图描述成北京大兴机场或真实生产地图。
- 不把模型回答描述为放行、登机、改签、车辆控制或真实运行指令。
- 不把当前 HTTP IP 写成 HTTPS、自有域名或永久地址；试用实例到期、释放或迁移后必须同步更新公开文档。
- 不把离线包的确定性事实解释写成携带了 DeepSeek、本地大模型或任意真实 API 密钥；离线包不得默认访问公网或服务端秘密配置。
