# M5-5 前端辅助交互接入计划

## 1. 目标

M5-5 把已经完成的事件草稿、缺失追问、人工复核提交、有限调度目标和方案事实解释接入现有五页实时工作台。前端只持有输入、草稿、解释结果和展开状态等临时交互数据；`RuntimeSessionSnapshot`、仿真时钟、场景版本、运行 revision、当前方案与候选方案继续只由后端和现有 `useRuntimeSession` 管理。

> 仅供教学仿真与辅助决策使用，不构成真实机场运行、放行、登机、改签或车辆控制指令。

## 2. 事件页范围

- 在“事件影响”页增加匿名运行事件录入区，支持 `auto` 与 `deterministic_only` 两种辅助模式。
- 请求固定绑定当前 `session_id + revision`，不允许前端自报仿真时间、场景版本或当前登机口。
- `needs_clarification` 显示逐字段追问和可选规范值；用户修改原输入后重新生成，不保存服务器草稿副本。
- `ready_for_review` 展示事件字段、逐字段来源和模型/规则来源；运行 revision 变化后标记草稿过期并禁止提交。
- 提交前必须分别确认事件字段和四选一确定性调度目标；提交继续调用既有人工复核接口，返回的新快照由共享运行控制器接管。
- 提交只允许在 `ready` 或 `paused`；候选出现后仍由现有方案页人工采用或保留。

## 3. 方案页范围

- 在“方案依据”页增加事实解释区，可选择当前方案或待确认候选、解释重点和可选匿名问题。
- 解释请求固定绑定当前 `session_id + revision + plan_id`；候选解释自动以当前方案为基线。
- 页面展示摘要、取舍、建议下一步及其引用的权威事实，模型来源和回退原因透明可见。
- revision 或方案集合变化后，旧解释标记过期；页面不自动重发解释请求，也不把解释当成采用候选命令。
- 解释区自然高度完整展开，不增加内部纵向滚动，不重复展示未被任何结论引用的大量原始事实。

## 4. 状态所有权

| 状态 | 所有者 | 前端行为 |
| --- | --- | --- |
| 仿真时钟、revision、任务/资源/航班/事件投影 | `RuntimeSessionService` + SQLite | 只消费共享快照 |
| 当前/候选方案 | 后端计划与运行投影 | 只展示和提交已有人工决定接口 |
| 事件输入、草稿与确认勾选 | 事件辅助组件 | 临时内存状态，刷新即消失 |
| 解释请求与结果 | 方案解释组件 | 临时内存状态，revision 变化即过期 |
| AI 配置与密钥 | 后端进程环境 | 前端不可读取、配置或回显 |

## 5. GitHub 与公网部署约束

- 前端 bundle 不包含 API key、提供方 URL、模型名或 DeepSeek 专用 SDK。
- 所有请求只使用同源 `/api/v1`，后续公网部署通过反向代理或同源后端工作，不依赖本机绝对地址。
- 无 AI 配置时事件规则解析、追问、人工提交、确定性规划和规则解释全部可用。
- 页面不发送姓名、证件号、联系方式等个人信息；输入区保留匿名教学仿真语义。
- M5-5 不选择托管商、不创建 GitHub 远程仓库、不发布公网地址；这些分别由 M6/M7 收口。

## 6. 验收标准

- [ ] 桌面与移动端可以完成事件输入、追问、复核、目标确认和提交。
- [ ] 提交成功后现有共享快照更新，候选不会自动采用。
- [ ] 当前/候选方案均可请求事实解释，每条结论可查看引用依据。
- [ ] 陈旧草稿和陈旧解释不会被当作当前事实继续操作。
- [ ] 模型未配置、失败或回退时界面仍可完成核心流程并显示安全来源。
- [ ] 离线只读状态禁用写入和辅助请求，不伪造 AI 结果。
- [ ] 前端专项、类型检查、生产构建、后端回归和真实浏览器检查通过。

## 7. 非目标

M5-5 不实现 M5-6 总验收，不接真实机场生产数据，不配置或测试真实密钥，不新增聊天机器人，不自动应用事件、自动采用候选或让模型生成自由排班。
