# 风险与安全声明

联保智调是教学仿真与辅助决策软件，不是机场生产控制系统。

## 明确限制

- 所有场景、任务、资源、位置和事件均为匿名合成或历史回放式教学数据。
- 系统不接入真实机场生产系统，不提供真实放行、登机、改签、旅客通知或车辆控制指令。
- 当前公网版本只支持单实例、单 Uvicorn worker 和 SQLite 持久化卷；不承诺高可用、横向扩容或生产级灾备。
- AI 只读取当前权威仿真快照进行解释和事件草稿辅助。它不能写入运行状态、推进时钟、采用候选、调度资源或替代人工确认。

## 故障行为

- AI 未配置、超时、提供方错误或输出不符合事实约束时回退到确定性规则；核心闭环仍可运行。
- SSE 断开时前端使用 REST 权威快照恢复；旧 revision 命令不会自动重放。
- 数据库或健康检查失败时，部署平台应停止流量并按发布计划回滚，不应把错误页面当作正常运行结果。

## 数据与密钥

- 不记录旅客个人信息、API key、模型提示词中的秘密或未脱敏外部数据。
- DeepSeek key 只通过平台 Secret Manager 注入后端进程；前端和构建产物不可读取。
- 报告、截图和演示视频必须经过人工脱敏复核。

本声明不构成机场运行、航空安全、交通运输或信息安全合规认证；公开部署前仍需由部署方完成平台、网络和数据保护审查。
