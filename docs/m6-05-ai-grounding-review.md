# M6-5 方案问答相关性与四分区修复审查

## 1. 审查结论

本次专项修复已完成。方案解释现在先回答用户实际问题，再分别给出方案摘要、方案取舍、任务变化和人工处理；四个分区具有独立职责，并且每条事实性结论只能引用当前 version/revision 下由后端生成的权威 `FACT-*`。真实 DeepSeek 可以改善表达和跨事实归纳，但不能创造事实、修改方案或替代人工决定。

本修复不进入 M6-5A，不提供机场平面图坐标、实时空间轨迹或真实机场生产状态。缺少空间事实时服务明确返回证据不足，并且不调用模型猜测。

> 仅供教学仿真与辅助决策使用，不构成真实机场运行、放行、登机、改签或车辆控制指令。

## 2. 问题与根因

- 旧响应只有摘要、取舍和建议下一步，前端的解释重点不足以形成职责明确的内容分区，因此不同问题容易得到相似结构和相似文字。
- 用户问题只是附加提示，没有独立的回答状态、匹配实体和相关证据，无法区分已回答、未提问与权威事实不足。
- 模型上下文默认截取前 20 条事实，被点名的后序任务可能没有进入上下文；合法但与问题无关的事实引用也可能通过旧校验。
- 任务、资源、航班、事件和主题没有同时用于证据裁剪，模型可能看到与点名任务无关的航班或事件。
- 当前尚无空间坐标契约；若直接让模型回答平面图位置，会把推测伪装成运行事实。

## 3. 契约与实现

- `PlanExplanationResponse` 回显实际 `focus` 和规范化 `question`，新增 `question_answer`。状态固定为 `not_asked`、`answered` 或 `insufficient_evidence`；已回答时必须包含权威证据 ID。
- `summary`、`tradeoffs`、`task_changes` 和 `manual_handling` 均为必填分区。摘要说明整体状态，取舍说明目标与量化代价，任务变化说明任务/资源/时间/路线或基线差异，人工处理说明人员需要核对、协调或决定的事项。
- 后端从当前场景版本或运行 revision 匹配方案、任务、资源、航班和事件 ID，并识别利用率、等待、路线、任务变化、事件、约束、目标取舍和人工协调等主题。具体主题优先于“方案”“任务”等泛化词。
- 实体 grounding 接受当前权威证据中唯一可确定的简写：`TASK-004` 可写为 `task4`、`task-4`、`task 004`、`任务4` 或全角形式，资源 `WC-01` 可写为 `wc1`，航班 `FL-SIM218` 可写为 `sim218`。输入先做 Unicode NFKC、大小写、分隔符和数字补零规范化；ASCII 字母数字边界防止 `task4` 误命中 `TASK-040`，同一简写指向多个实体时不选择任意结果。
- 被问题点名的实体事实优先进入最多 100 条权威证据；发送给模型的有限上下文会排除与点名任务无关的任务、航班和事件。
- `question_answer` 与当前重点分区都必须引用问题相关证据。模型即使引用存在的 `FACT-*`，只要与问题无关，也会被判为 `invalid_model_output` 并回退确定性解释。
- DeepSeek 把单项分区返回为对象而不是数组时会被安全规范化；未知字段、未知事实、实体边界不一致、可执行指令和安全字段覆盖仍被拒绝。
- 空间位置、坐标、平面图、实时轨迹或现场状态问题在 M6-5A 前返回 `question_not_grounded`，公开 `insufficient_evidence`，不调用模型、不编造答案。

## 4. 前端结果

- “向 AI 提问”改为多行输入；返回结果顶部独立显示问题原文、回答状态、直接答案、匹配对象和完整事实引用。
- 四个分区全部返回并自然展开；所选重点只决定哪一部分必须直接围绕问题展开，不再隐藏其他分区。
- 每个分区显示自己的职责说明，当前重点具有明确视觉标记；结果继续随 revision、方案、重点或问题变化标记过期。
- 方案解释板块没有内部滚动。390px 移动端将事实 ID 与证据正文改为上下堆叠，避免长 ID 把正文挤成狭窄字符列。

## 6. 状态所有权与禁止事项

- 仿真时钟、事件应用、任务状态、当前/候选方案、CP-SAT、硬约束、revision 和人工决定仍由原后端权威链唯一拥有。
- AI 仍是只读解释器；`modifies_plan=false`、`requires_human_confirmation=true` 和完整教学仿真安全声明不可覆盖。
- 不把问题、模型输出或前端选择写成运行事实，不自动应用事件、采用候选、推进时钟或触发外部控制。
- 不提交 API key、DPAPI 配置、内部提示词、提供方原始响应或错误正文；不接未经授权的机场图、真实生产数据、个人信息或外部控制系统。
