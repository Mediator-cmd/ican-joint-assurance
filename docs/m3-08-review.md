## 4. 回退、双失败与恢复

1. 中断 `/api/v1/demo` 后，页面切换为“本地演示数据”，当前页面和方案选择保持不变。
2. 恢复 API 后，应用内重新加载返回“服务数据”。
3. 同时断开 API 与静态文件后，只显示面向用户的统一错误，不暴露本机路径或堆栈。
4. 恢复网络并点击“重新载入”后，再次返回“服务数据”。

双失败公开文案为：

> 演示数据加载失败：数据服务暂不可用，本地演示数据也未能载入。请确认项目服务已启动后重试。

故障注入期间出现的 `ERR_FAILED` 和 `ERR_INTERNET_DISCONNECTED` 属于预期网络错误；正常在线阶段无控制台错误。
