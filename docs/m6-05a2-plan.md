# M6-5A-2 空间 AI 问答与地图聚焦实施计划

## 目标

让调度总览中的 AI 直接回答当前匿名机场空间态势问题，并把答案引用的任务、资源、事件和区域在同一张图上聚焦。整个链路绑定当前运行会话和 revision，只能使用后端生成的 `SPATIAL-FACT-*`，模型只负责有限事实的中文组织，不能生成坐标、路线、事件、方案或运行操作。

> 仅供教学仿真与辅助决策使用，不构成真实机场运行、放行、登机、改签或车辆控制指令。

## 请求与响应契约

- 请求包含 `session_id`、`revision`、非空问题、当前可选的任务/资源/事件选择和 `auto | deterministic_only` 模式。
- 后端在一次调用内取得同 revision 的 `RuntimeSpatialView`；陈旧 revision、未知会话、未登记布局或不属于当前 overlay 的选择均明确拒绝。
- 响应包含实际绑定的 session/revision/仿真时间、回答状态、引用事实、匹配实体、地图聚焦 ID、来源透明度和未解决问题。
- `answered` 必须至少引用一个本次响应中的 `SPATIAL-FACT-*`；`insufficient_evidence` 必须明确说明未知位置或对象不能推断。
- 地图聚焦 ID 只能来自当前布局和 overlay，并且必须由答案引用事实支持；响应固定 `requires_human_confirmation=true`、`modifies_runtime=false`。

## 规则 grounding

- 复用已有实体简写规则，支持唯一可确定的 `task4`、`任务4`、`wc1` 等输入，不完整匹配或歧义时不猜测。
- 当前地图选择优先加入相关事实；问题中的明确实体优先于宽泛主题。
- 有限主题包括总体态势、位置、事件、资源/进度、任务/路线、候选变化和人工边界。
- 问题没有可核对实体或主题、询问未登记区域/真实机场位置、要求坐标或要求执行控制时，直接返回规则型证据不足，不调用模型。

## 模型增强

- 复用现有 OpenAI-compatible/DeepSeek 后端配置，不新增浏览器密钥或提供方 SDK。
- 只发送规范化问题、当前选择、允许聚焦的 ID 和经过筛选的 `SPATIAL-FACT-*`；不发送 SQLite、审计、本机路径、真实坐标、会话 ID、revision 或密钥。
- 模型输出只允许回答草稿、引用 ID、聚焦 ID 和未解决问题；任何未知事实引用、越权聚焦、状态不一致、坐标/操作字段或结构错误都视为非法输出并规则回退。最终展示正文与人工确认提示由后端按模型选中的已核验引用重新构造，模型自由文本不直接透传，避免在合法引用旁夹带无依据位置、进度或操作建议。
- 未配置、超时、提供方错误和非法输出沿用现有透明回退原因；规则答案在无模型部署中仍完整可用。

## 前端联动

- 空间问答放在态势图之后，默认带入当前地图选择，可切换智能辅助/仅规则。
- 回答展示实际问题、来源、revision/仿真时间、`SPATIAL-FACT-*` 引用、匹配对象和聚焦对象。
- 后端验证后的聚焦 ID 在地图上形成独立高亮，不替代当前/候选路线语义；点击引用可复用现有选择与详情页。
- session/revision、问题、模式或选择变化后旧答案立即失效并清除地图 AI 聚焦，不能冒充当前事实。

## 验证清单

- 无模型规则回答、真实主题 grounding、简写、当前选择、未知位置、控制请求、旧 revision 和无副作用。
- 模型成功、超时、提供方错误、非法引用、越权聚焦和结构错误回退。
- 前端 API 严格校验、陈旧答案清除、地图多对象聚焦、390px 无横向溢出。
- 后端/前端全量、类型检查、生产构建、浏览器动态流程、Git 差异与敏感信息检查。

## 禁止事项

- 不让模型生成或修改 normalized 坐标、路径几何、资源进度、事件状态、当前方案或候选方案。
- 不自动应用事件、采用/拒绝候选、推进时间、控制车辆或输出真实机场运行指令。
- 不读取、回显、提交 `.runtime` 配置或密钥；不接真实机场生产数据、个人信息或未知来源机场图。
