# M2 实现审查报告

## 审查范围

- Pydantic 方案与指标模型；
- FIFO 调度、事件应用、最短路径、CP-SAT 优化和独立约束检查；
- 演示 JSON 导出；
- React 运行态网站及桌面/移动响应式布局；
- 安装、构建、测试和安全边界。

## 已解决问题

1. 首次把 OR-Tools 安装到全局 Anaconda 时发现与 `mem0ai` 的 protobuf 版本冲突。已移除本次新增的全局包、恢复 protobuf 5.29.3，并把 OR-Tools 隔离到项目 `.venv`。
2. 方案状态最初只由调度器赋值，模型本身未阻止“有未分配任务却标记全部可执行”。已增加 `Plan` 状态不变量校验。
3. 独立约束检查器最初未复核 `wait_minutes`。已增加等待时间一致性检查和篡改回归测试。
4. 浏览器首次加载产生 favicon 404。已增加项目图标并复测控制台无错误。
5. 首版移动截图存在完整 ISO 时间和英文旅客组标签。已改为短时间及中文业务标签。
6. 前端最初使用根路径读取 JSON，不利于子路径部署。已改用 `import.meta.env.BASE_URL`。

## 验证结论

- 后端：19 项测试通过；覆盖合法导入、错误数据、FIFO、资源冲突、时间窗、事件应用、优化器确定性和篡改检测。
- 优化对比：FIFO 完成 4/5 项、P1 完成率 50%；事件后 CP-SAT 完成 5/5 项、P1 完成率 100%；两者硬约束违规均为 0。
- 前端：TypeScript 检查通过，生产构建通过。
- 浏览器：1440×1000 和 390×844 均显示非空页面；模式切换、未分配任务和优化结果正确；390px 视口无页面级横向溢出。
- 安全：页面固定显示教学仿真与辅助决策提示，场景标记为 `synthetic`，使用虚构 `SIM` 航班编码。

## 剩余风险

- 当前网站读取构建前生成的静态 JSON，场景导入和实时重规划要在 M3 接入 API。
- 当前 CP-SAT 模型已验证小型演示场景，尚未进行 100/500/2000 任务规模测试。
- 目前没有持久化、用户权限或公网部署，不应描述为生产系统。
- 自然语言事件输入和 AI 解释尚未实现，核心调度不依赖 AI。

## 审查结论

未发现阻塞 M2 提交的剩余问题。下一阶段应保持现有演示 JSON 契约，用 FastAPI 替换静态读取，并保留当前文件作为离线回退和回归夹具。
