# 联保智调最终展示蓝图

## 1. 最终交付形态

最终成果确定为一个可在浏览器直接操作的运行态 Web 控制台，配套 FastAPI 服务、可复现仿真数据、自动化测试和 5 分钟以内演示视频。

网站不是项目介绍页。评委打开首屏即可看到持续推进的仿真时间、航班扰动、保障任务、资源状态和调度结果，并能完成“加载场景—启动运行—观察状态变化—事件自动生效—确认重规划—比较指标—导出任务清单”的完整闭环。

所有页面固定显示：

> 仅供教学仿真与辅助决策使用，不构成真实机场运行、放行、登机、改签或车辆控制指令。

## 2. 评委首屏需要看到什么

1. 持续推进的当前仿真时间、开始/暂停/倍速控制、场景名称和数据分类标识。
2. 延误、登机口变更等事件流及等待、触发、重规划、待确认和完成状态。
3. FIFO 基线与优化/重规划方案的切换控件。
4. 关键任务完成率、平均等待时间、未完成任务和资源利用率。
5. 可复核的任务时间线：任务、资源、路线、移动时间、服务时间和状态。
6. 资源面板：摆渡车、轮椅、服务人员的空闲、移动、等待、服务中状态，当前位置、下一可用时间和利用率。

## 3. 五分钟演示脚本

### 0:00—0:40 场景与问题

- 打开运行态总览，说明这是合成数据驱动的仿真实时场景。
- 展示两个航班、五个匿名保障任务和四个有限资源。

### 0:40—1:30 FIFO 基线

- 启动仿真时钟，展示先到先服务计划。
- 查看任务和资源随时间进入移动、等待与服务状态。

### 1:30—2:30 注入扰动

- 等待航班延误和登机口变更按仿真时间自动生效。
- 展示受影响任务、位置变化和系统自动进入重规划状态。

### 2:30—3:40 重规划与解释

- 查看待确认候选方案，确认采用后展示调整前后任务、资源和时间变化。
- 解释为什么某项任务被重新分配或未能完成。

### 3:40—4:30 量化比较

- 对比关键任务完成率、平均等待时间、未完成任务和资源利用率。
- 强调所有方案均经过独立硬约束检查。

### 4:30—5:00 技术与安全边界

- 展示测试结果、仿真数据分类和 AI/优化器边界。
- 说明系统只提供教学仿真与辅助决策，不接管真实生产系统。

## 4. 页面发展顺序

| 阶段 | 网站能力 | 数据来源 |
| --- | --- | --- |
| M2 雏形 | FIFO/事件后 FIFO/CP-SAT 切换、指标、未分配任务、事件列表、任务时间线、资源利用率 | Python 调度引擎导出的静态 JSON |
| M3 API 化 | 场景导入、规划、事件注入、重规划和方案查询 | FastAPI |
| M4 运行态 | 权威仿真时钟、动态任务/资源状态、事件自动生效、滚动重规划、人工确认、SSE 推送与完整演示流程 | FastAPI + SQLite + SSE |
| M5 AI 接入 | 自然语言事件输入、字段追问、结果解释 | 可替换 AI 接口 + 规则回退 |
| M6-M7 发布 | 性能对比、报告导出、稳定公网版本 | 可复现仿真场景 + 回归测试 |

M2 前端只读取由 Python 引擎生成的 JSON，避免在浏览器内伪造指标。M3 保持相同 TypeScript 数据结构，把静态读取替换为 API 请求。M4 再将一次性快照升级为后端权威运行会话；静态 JSON 只保留为明确标识的离线只读降级。

## 5. 最终验收标准

- 在干净环境中按 README 能启动前后端。
- 评委无需查看代码即可完成一次完整演示。
- 页面展示的数据能够由命令行重新生成，不能手工伪造指标。
- 页面无需手动刷新即可显示仿真时间、任务、资源、事件和方案状态变化。
- 事件到时自动触发滚动重规划，已完成和正在执行的工作不被改写，新方案需人工确认。
- 所有可执行方案的硬约束违规数为 0。
- 演示流程连续运行三次无阻塞。
- 桌面和移动视口无文字溢出、遮挡或空白主视图。
- 页面、报告和视频不出现未授权真实机场、航班或旅客数据。
