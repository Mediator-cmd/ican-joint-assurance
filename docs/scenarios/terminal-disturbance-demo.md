# 航站楼连续扰动教学场景

对应数据文件：`data/scenarios/terminal-disturbance-demo.json`

## 场景目的

在 08:00 至 09:30 的有限仿真窗口中，展示 3 个虚构航班连续受到延误和登机口调整时，轮椅、服务人员与摆渡车辆如何随新事实滚动重规划。场景同时保留 FIFO 与 CP-SAT 的确定性对照，并确保第二次事件后仍有新的事件、候选和后段任务可观察。

场景只用于教学仿真。所有航班、任务和资源编码均为虚构或匿名 ID，不代表真实机场、航班、旅客或生产运行数据。

## 初始状态

- 虚构航班：`FL-SIM102`、`FL-SIM218`、`FL-SIM330`。
- 匿名保障任务：`TASK-001` 至 `TASK-010`，覆盖轮椅转运、陪同引导、摆渡转运和登机协助。
- 保障资源：`WC-01`、`WC-02`、`AGENT-01`、`AGENT-02`、`BUS-01`；`WC-02` 从 08:40 可用，`AGENT-02` 从 08:18 可用。
- `flights` 和 `tasks` 表示扰动发生前的基线事实；`events` 是后端按 `occurred_at` 原子应用的一次性事件目录。
- 初始 FIFO 安排 9/10，关键任务完成率 75%；初始 CP-SAT 安排 10/10，关键任务完成率 100%；两者硬约束违规均为 0。

## 有限事件序列

| 时间 | 事件 ID | 中文事实 |
| --- | --- | --- |
| 08:00 | `EVT-SIM102-DELAY` | SIM102 预计离港时间顺延 25 分钟 |
| 08:04 | `EVT-SIM218-GATE` | SIM218 保障地点由 GATE-W03 调整至 GATE-E01 |
| 08:16 | `EVT-SIM330-GATE` | SIM330 保障地点由 GATE-E01 调整至 GATE-W03 |
| 08:28 | `EVT-SIM218-DELAY` | SIM218 预计离港时间顺延 15 分钟 |
| 08:40 | `EVT-SIM330-DELAY` | SIM330 预计离港时间顺延 10 分钟 |
| 08:52 | `EVT-SIM218-GATE-RETURN` | SIM218 保障地点由 GATE-E01 调整至 GATE-W03 |

所有事件 ID、发生时间和载荷固定。每条事件只能应用一次并生成新的场景版本和滚动候选；不存在前端随机事件、无限流或窗口结束后的循环回放。

## 滚动规划语义

1. 事件到达前不会提前改变航班、任务或计划。
2. 事件生效时，后端冻结已完成、移动中、等待中和服务中的任务，只重新安排尚未开始或待协调任务。
3. 每个候选由 CP-SAT 生成并经过独立硬约束复核，违规不为 0 时不得进入待确认状态。
4. 后段事件发生时，可能因所有相关任务已经锁定而得到“0 项调整”的新候选；页面必须如实说明复核未改变安排，不能为了制造变化而篡改已发生事实。
5. 每个候选仍需人工明确采用或保留；确认后才允许继续推进时间。
6. 全部事件处理后，时间继续单向推进到 09:30 的 `completed`，不会回到 08:00。

## 预期验证点

1. 事件、任务、航班、资源和区域引用全部有效，所有时间带时区且位于 08:00 至 09:30 窗口内。
2. 六条事件按时间严格有序、ID 唯一、每条只应用一次，并分别产生唯一候选 ID。
3. 当前/候选方案均覆盖全部 10 项任务，或用结构化中文原因列出未分配任务。
4. 页面能复核每项安排的航班、资源、服务时段和路线，以及候选相对当前计划的真实差异。
5. 事件完成后场景版本保持 V7，09:30 进入完成态且不会循环。

该场景显式标记为 `data_classification: synthetic`。

> 仅供教学仿真与辅助决策使用，不构成真实机场运行、放行、登机、改签或车辆控制指令。
