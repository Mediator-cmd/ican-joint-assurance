# M6-5A-1 实时二维空间态势前端审查

## 1. 审查结论

M6-5A-1 已完成。调度总览现在直接绘制与当前 `RuntimeSessionSnapshot` 同一 `session_id + revision` 的匿名机场二维空间态势；任务、资源、事件、当前方案与真实发生变化的候选路线均来自 M6-5A-0 后端投影，浏览器不再建立地图专用时钟、随机运动、循环事件、规划器或第二份运行快照。

> 仅供教学仿真与辅助决策使用，不构成真实机场运行、放行、登机、改签或车辆控制指令。

## 2. Revision 绑定与状态所有权

- `useRuntimeSpatialView()` 只按当前快照的 `session_id + expected_revision` 读取空间接口；仿真时间变化会重新读取后端投影，但不会在浏览器插值或自推进。
- 请求切换或组件卸载时取消旧请求；响应的 session/revision 与当前快照不一致时停止绘制，409 revision 冲突进入等待最新权威快照状态。
- 地图组件再次按 `expectedRevision` 拒绝陈旧视图；加载、断线或布局不可用时不会保留旧路线冒充当前事实。
- 地图选择只复用调度总览现有的任务、资源、事件选中状态，并可跳转到既有详情页；选择不增加 revision、不改变运行状态。

## 3. 一一对应与过程表达

- 默认场景始终绘制 10 条当前任务路线；每条路线均在右侧完整清册中保留独立选择入口，重叠路线不会造成任务消失。
- 候选路线只为后端 `changed_candidate_task_ids` 中真实发生变化的任务绘制虚线；当前实线在人工采用前始终保留。
- 5 个资源标记严格使用后端位置和进度。对象重叠时只做确定性三列视觉错位，并用连接线指回权威坐标，不改变业务位置。
- 6 个一次性事件逐个保留独立 ID、状态、位置、说明和详情跳转；事件状态只随运行快照与空间接口更新。
- 图层开关只控制区域、当前路线、候选路线、任务、资源与事件的可见性，不修改底层事实。

## 4. 可用性与视觉边界

- 态势图位于调度决策板之后，包含覆盖率、实线/虚线图例、任务路线清册、任务/资源/事件焦点卡和过程显示规则。
- 放大视图与普通视图共用同一数据和选择；桌面与 390px 移动视口均无文档级横向溢出。
- 原创匿名 SVG 继续明确标注 `normalized Cartesian` 和“非真实机场地图”，没有导入北京大兴机场图片、真实坐标、商业地图或内部运行图。
- 完整安全声明在空间板底部持续展示；候选采用仍只能通过既有人工确认流程完成。
